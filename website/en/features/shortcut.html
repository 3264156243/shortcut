Details

From "add it" to "open it", with nothing in between.

Global hotkey

Alt+Space by default — the panel appears from any app, no need to go back to the desktop first.

Automatic icons

Icons are extracted from the program itself; you can also point to an icon file or let it fetch a site favicon.

Import installed apps

Scan installed programs and add them in bulk instead of hunting for each path.

Tabs and groups

Organise with tabs and groups, drag to reorder, move items across groups.

Search and keyboard navigation

Search by name, path or note; arrow keys to select, Enter to launch — no mouse required.

Four entry types

Apps, folders, plain files and web URLs, plus shortcut groups and BAT scripts.
