Details

Send it and forget it; expiry handles the rest.

Chunked uploads

Large files are split into chunks; an interrupted network does not force you to start over.

Automatic expiry

Every file can carry a time-to-live and is deleted when it expires — nothing to clean up by hand.

Hash verification

Both upload and download verify integrity, so you never end up with a corrupt file.

Text as well as files

Send a snippet or a link straight to the other clipboard — handier than copying across devices.

Never touches a third-party cloud

Files stay on the server you deployed; links are yours to revoke at any time.

Share links

Generate a download link with an expiry and send it to someone who does not even need the client.
