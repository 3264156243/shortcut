Details

Lightweight, but nothing essential is missing.

Multiple walls

Work, personal and project walls stay separate, each with its own ordering.

Long text and reminders

Notes can hold long content; to-do items can have a reminder time that pops up in the SC ball.

Reminder popups

Jump to the item or mark it done straight from the popup — no need to open the main panel.

Pin from your phone

Pin a task on mobile and it appears on the desktop immediately; offline desktops queue it and pick it up when back.

Two-way completion

Tick it off on the desktop and it disappears from the phone, and vice versa.

Task list ball

Push important tasks into the SC task-list ball so the remaining items stay in sight.
