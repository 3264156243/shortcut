One little ball
holding music, tasks and system stats

Most of the time it is a slim pill that takes almost no space. Open it while listening to music and you get the cover, lyrics and playback controls. Turn on mouse click-through and it stops blocking desktop clicks entirely — use the hotkey to switch it back when you want to click it.

Details

It lives on your desktop, so every detail respects your attention.

Collapsed, mini, expanded

When collapsed the width follows the content; it keeps a fixed width while music plays so it does not jump around.

Music cover and lyrics

Built-in NetEase Cloud Music bridge: cover, progress, word-by-word lyrics, long-line scrolling, and half-a-line lead time.

Task reminder ball

Reminders pop up when a task is due; jump to it or mark it done in one click.

Hardware stats and balance

CPU / GPU / memory usage and temperature at a glance; DeepSeek balance refreshes every minute and splits into a small side ball while music plays.

Click-through mode

Fully transparent to mouse input so it never blocks the desktop; still callable by hotkey. Alt+B toggles it.

Its own always-on-top window

Independent from the main panel: close the panel and the ball stays.
