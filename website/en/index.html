02 / Task Wall

Not another to-do app.
Put the work in front of you.

Each task is a note. Add a title, write the details, set a reminder. Separate walls keep work, life and quick thoughts apart without letting them disappear.

  • WriteA short line or a full long-form note
  • RemindSC Ball brings it back when the time comes
  • SyncPin it on your phone, continue at your desk

01

Phone control

Use your phone as a keyboard and trackpad. Connect directly on the same Wi-Fi or operate the computer remotely through the cloud.

Keyboard, trackpad and clipboard → 02

File transfer

Send files or text between phone and computer without a third-party drive. You choose the share window; expired items are cleaned up automatically.

Send and receive → 03

Android app

Pick up tasks, transfer files and check the connection from your phone, or use the mobile site in a browser without installing anything.

View the Android app → 04

Screenshots and translation

Alt+S copies the whole screen to the clipboard; Alt+E translates selected text in a note that stays above other windows.

View shortcuts → 05

System dashboard

CPU, GPU and memory usage and temperature live in SC Ball; open the dashboard when you want the full picture.

View system status → 06

Local-first

Shortcuts, tasks and usage history stay on your computer by default. Data only moves through the secure ShortCut link when you actively use phone handoff.
