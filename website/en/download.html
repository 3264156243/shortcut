Installation

Three steps

下载installer

从上面任一渠道下载 ShortCut_x.y.z_x64-setup.exe。

Run the installer

若出现 SmartScreen「未知发布者」提示，点「更多信息 → 仍要运行」。installer当前未做代码签名。

Launch with normal privileges

Do not run as administrator: elevated processes trigger Windows UIPI, which breaks dragging files from Explorer onto the SC Ball.

Installation issues

Things you may run into

What about the "unknown publisher" warning?

installer未做代码签名（Authenticode），Windows SmartScreen 会提示未知发布者。点「更多信息 → 仍要运行」即可。更新包本身有签名校验，不会被替换。

Will upgrading lose my settings and tasks?

不会。配置与任务存放在 %APPDATA%\\ShortCut\\shortcut，与安装目录分离；每次写入还会Kept最近 3 份备份。

Old versions (2.4.x and earlier) fail to update in-app?

是的。旧版的「检查更新」读取的是 Electron 时期留下的清单格式，该问题在 2.5.1 修复。手动下载一次 2.5.1 之后即可正常自动更新。

Is there a portable build?

目前只提供 NSIS installer。它会把自启与快捷方式一并配置好；解压即用的便携版可能后续提供。
