How feedback is handled

Recorded on the project server

不存在第三方平台，也没有注册流程；Details按 JSONL 追加保存在服务端数据目录。

No raw IP stored

只保存加盐哈希用于限流，不保存 IP 明文；同一 IP 每小时最多 5 条、每天 20 条。

Replies are not guaranteed

缺少Contact时只做记录。如果是能复现的 Bug，会优先修。

You do not need to send these
  • 「安装时提示未知发布者」——安装包未做代码签名，点「更多信息 → 仍要运行」即可
  • 「旧版本检查更新失败」——2.4.x 及更早的已知问题，手动装一次 2.5.1 后正常
  • 「局域网控制连不上」——先确认手机与电脑在同一 Wi-Fi，且没开 AP 隔离
