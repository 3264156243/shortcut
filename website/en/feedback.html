How feedback is handled

Recorded on your own server

No third-party platform and no sign-up. Entries are appended as JSONL under the server's data directory.

No raw IP address stored

Only a salted hash is kept for rate limiting. The same IP is limited to 5 submissions per hour and 20 per day.

Replies are not guaranteed

Without contact details an entry is only recorded. Reproducible bugs are fixed first.

Already sent feedback? Check for replies

After submitting you receive a feedback ID and a lookup token. Both are required to view replies.

You do not need to send these
  • "Unknown publisher" during install — the installer is not code-signed yet; choose "More info → Run anyway"
  • Old versions fail to check for updates — a known 2.4.x issue; install 2.5.1 once manually and it works afterwards
  • LAN control cannot connect — make sure phone and PC are on the same Wi-Fi and AP isolation is off
