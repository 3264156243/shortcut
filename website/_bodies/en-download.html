Installation

Common questions

What about the “unknown publisher” warning?

The installer does not have a Windows digital signature yet, so SmartScreen may show an unknown publisher. Choose “More info → Run anyway”. Updates are still checked before they are installed.

Will upgrading remove my shortcuts or tasks?

No. Shortcuts, tasks and settings are preserved. ShortCut also keeps the three most recent local backups.

What if a very old version cannot check for updates?

Download 2.5.1 or a newer build once and install it over the old version. Your data will be preserved and in-app updates will work again.

Is there a portable build?

ShortCut is currently distributed as a Windows installer, which also sets up startup and Start menu entries. A portable build is not available yet.
