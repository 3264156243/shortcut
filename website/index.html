产品简介

从一个启动面板，长成桌面效率中枢

ShortCut 最初是一个桌面快捷方式管理工具，用于减少在桌面、开始菜单和文件夹之间反复查找内容的时间。

随着功能扩展，ShortCut 已加入任务墙、长文本便签、待办提醒、翻译、电脑驾驶舱和 SC球 灵动岛，并将继续扩展更多实用工具板块。

用户可以通过左侧导航在不同板块之间切换，同时保留统一的窗口、主题和快捷操作体验；SC球 常驻桌面，可显示音乐、任务提醒、驾驶舱数据和 DeepSeek 余额。

核心板块二

任务墙

记录临时事项、待办任务和较长的文本内容。任务条可自由拖动排列，多种类型自由组合。

  • 创建多个任务墙，每个可单独命名。
  • 自由拖动任务条位置，拖动中的任务自动置顶。
  • 创建普通文本任务、长文本便签、带时间的待办提醒。
  • 可同时启用长文本与待办提醒。
  • 双击任务条打开编辑弹窗，修改标题、正文、类型与提醒时间。
  • 删除任务前二次确认；双击任务墙名称可重命名。
  • 双击空格快速聚焦任务输入栏。
核心板块三

SC球 灵动岛

常驻桌面的悬浮效率球，聚合音乐、任务、驾驶舱和 DeepSeek 余额，让关键信息随时可见。

  • 收起、迷你、展开三种固定状态，宽度随内容自适应。
  • 网易云音乐：封面、歌词、进度与播放控制，支持逐字歌词和长歌词轮播。
  • 任务到时自动弹出提醒球，任务清单球支持完成、移除与跳转定位。
  • 驾驶舱数据：CPU、GPU、内存占用与温度。
  • DeepSeek 余额：每分钟刷新，播放音乐时分离为右侧小圆球。
  • 全局快捷键：Alt+Z 上一首、Alt+X 播放暂停、Alt+C 下一首、Alt+U 切换任务清单。

核心板块四

手机与桌面联动

无需安装手机 App，手机浏览器打开联动门户，扫码或输入 6 位绑定码即可与桌面 ShortCut 互联，双向传文件、发文本、推送任务。

  • 手机访问 shortcut.326415.xyz/mobile，扫码或输入桌面端“验证绑定”页的 6 位绑定码完成绑定。
  • 任务墙互通：手机查看 / 推送任务至桌面任务墙，桌面端同步显示。
  • 文件快传：手机与桌面双向发送文件与文本消息，云端中转、两端同步。
  • 临时共享：6 位接收密码领取共享文本或文件（可选加密密码与时长）。
  • 绑定信息保存在手机本地，一次绑定持续有效，可随时更换或解除。

常见问题

你可能想问

ShortCut 支持哪些系统？

当前主要面向 Windows 系统。

可以添加网页地址吗？

可以。输入网址时如果没有填写协议，ShortCut 会自动补全后使用浏览器打开。

为什么部分程序没有原始图标？

部分程序的图标可能无法直接提取。ShortCut 会尝试其他提取方式，仍然失败时使用系统默认图标。

数据会上传到网络吗？

当前快捷方式、任务墙和设置数据保存在本地。

安装新版本会丢失任务和快捷方式吗？

正常覆盖安装不会删除用户配置。正式更新前仍建议保留重要配置的导出备份。

为什么旧版本不能自动更新？

早期版本没有包含更新组件，需要先手动安装一次带更新功能的新版。

如何检查更新？

点击主页面左下角、设置按钮上方的更新入口。

检查到更新后会自动下载吗？

不会。软件会先展示版本号和更新内容，用户确认后才开始下载。

SC球 需要激活才能使用吗？

需要。未激活时程序会先进入激活页面，激活通过后 SC球 才会显示。

DeepSeek 余额如何配置？

在 SC球 设置的 DeepSeek 板块填写自己的 API Key，余额每分钟刷新，点击余额可打开 DeepSeek 平台。
