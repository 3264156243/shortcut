# ShortCut 2.4.4

## 语音输入（新板块）

- 全新语音输入板块：Alt+H 弹出胶囊麦克风，说话时识别文字暂存进胶囊（不再实时写入光标，说多少句都不会断），勾选后统一处理并输入光标。
- 胶囊形态：左侧取消、中间识别文字（超出向左滚动）、右侧确认；支持拖拽移动、右下角调整大小，位置与大小自动记忆。
- 按键控制：空格=暂停/继续识别，回车=确认处理并输入，ESC=取消不输入；语音输入时焦点在胶囊上按键直达。
- 识别文字流式累加：已定稿句子只追加一次、进行中句子覆盖式更新，杜绝识别重复污染；前半段/后半段都不会丢失。
- 结构整理（勾选时调用 LLM）：合并重复内容、修正错别字、语句通顺；原文明确列举（第一/第二/几点/多个任务）或模型输出多行时自动编号 1. 2. 3.，普通一句话输出通顺段落不编号。
- 输入注入改为 SendInput Unicode 直输，不碰剪贴板，不再污染复制粘贴框。
- 使用统计：语音板块展示今日/历史调用次数与转写字数（按天记录）。
- 管理后台用户分组权限新增「语音输入」勾选项（自动同步注册）。

## 修复

- 修复语音识别文字反复删掉又出现的问题（增量追加模型）。
- 修复结构整理结尾出现双句号的问题。
- 修复胶囊圆角直角阴影（外阴影改为跟随圆角的 drop-shadow）。
