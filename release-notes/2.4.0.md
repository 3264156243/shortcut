# ShortCut 2.4.0

## SC球

- 新增驾驶舱数据模块：显示 CPU / GPU / 内存占用与温度，无数据显示“?”。
- 新增 DeepSeek 余额模块：每分钟刷新，API Key 由用户自行填写，点击余额可打开 DeepSeek 平台。
- 播放音乐时 DeepSeek 余额会分离成右侧小圆球，退出播放后融回；小球随 SC球 实时移动。
- SC球 收起状态宽度随内容自适应，播放音乐时保持固定宽度。
- SC球 设置面板按模块分区：SC球、音乐、任务、驾驶舱、DeepSeek。

## 快捷键

- 新增音乐全局快捷键：Alt+Z 上一首、Alt+X 播放暂停、Alt+C 下一首。
- 快捷键介绍页同步更新。

## 其他

- 音乐、任务、驾驶舱、DeepSeek 均有独立开关。
- 任务清单与任务墙完成状态双向同步，任务删除后自动清理清单记录。
