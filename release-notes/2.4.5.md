# ShortCut 2.4.5

## 电脑控制（新板块）

- 全新「控制」板块：手机远程控制电脑——手机端打字直接进电脑光标、触控板控制鼠标、常用快捷键组合键、读取/粘贴/清空电脑剪贴板。
- 云端转发模式（推荐）：手机在任何网络（4G / 别处 Wi-Fi）都能控制电脑，绑定身份自动配对，无需输入连接码；桌面端状态卡显示二维码，手机扫码直达控制页。
- 局域网直连模式：手机与电脑同一网络时延迟最低，桌面端显示直连地址与二维码，两种模式自由切换。
- 手机控制页实时状态：云端通道 / 输入注入 / 桌面在线一目了然；指令失败弹提示不再静默；连接半死自动检测重连。
- 快捷键不干扰输入状态：输入时点快捷键键盘不收起，非输入状态点击不会误弹键盘。
- 管理后台用户分组权限新增「电脑控制」勾选项（自动同步注册）。

## 文件快传

- 分片上传 SHA-256 哈希完整性校验：桌面端与移动端逐分片校验，杜绝传输损坏；下载响应附带完整文件校验头。
- 过期自动清理：过期消息、孤立分片、失效分享、过期令牌定时自动清理；管理后台新增消息保留时长配置（1~720 小时，默认 24）。
- 移动端共享弹窗重构：创建 / 领取 / 历史三区块收进独立弹窗，主页面专注文件互传。

## 移动端

- 绑定成功自动返回联动首页，无需手动跳转。
- 控制引导页改为云端连接单一主入口，局域网直连收进折叠项。
- 页面进入/刷新始终定位顶部，不再恢复上次滚动位置。
