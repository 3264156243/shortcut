🖥️ 电脑控制

用手机向电脑打字、控制鼠标、使用电脑粘贴板

先完成绑定

电脑控制使用 ShortCut 的绑定身份自动配对。请先在桌面 ShortCut「联动绑定」获取 6 位绑定码完成绑定。

🔗 去绑定桌面端输入绑定码，一次绑定持续有效 ›
☁️ 云端连接 推荐 任何网络可用（4G / 别处 Wi-Fi 均可），自动配对无需输码 ›

前提：电脑端 ShortCut「控制」板块已启动「云端连接」。

📶 局域网直连 更快

手机与电脑连接同一网络时使用，延迟最低。桌面端「控制」板块会显示形如 192.168.x.x:9823 的地址：

更方便：直接用手机相机扫描桌面端「控制」板块的二维码。
