# 0.2.1

## 修复：局域网直连后打字没有同步

查到是**三个问题叠加**，每一个单独都足以让「打字没反应」：

- **电脑端拒绝输入时被误当成成功**：桌面端返回「注入失败」时 HTTP 状态仍是 200，
  只能看响应里的 `ok` 字段。此前只看状态码，于是界面认为已发送、电脑毫无反应。
- **失败没有任何提示**：打字与退格被设成静默处理，出了问题看不到任何原因。
  现在失败会明确告诉你（注入器未就绪 / 电脑拒绝按键）。
- **长文本被服务端拒绝**：单次打字上限 2000 字节（约 666 个汉字），
  超出会被直接拒绝。现在会自动按字节分片发送，中文和 emoji 都不会被切坏。

## 修复：输入法组合判断

- 拼音选字过程中不再同步（避免把拼音打到电脑上），选字完成后立即同步中文
