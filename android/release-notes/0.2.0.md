# 0.2.0

## 新增：应用内更新

- 启动时自动检查新版本，发现更新会显示版本号与更新说明
- 设置 → 关于 → 「检查更新」可手动检查
- 下载带进度显示，并校验安装包完整性后才允许安装
- 升级为覆盖安装，**已绑定的电脑与本机数据都会保留**

## 修复：电脑控制

- **输入不同步**：改用精确的输入法状态判断（此前会误判导致完全不发送）
- **键盘按键错误**：字母键此前被当成快捷键组合发出，现已修正为单键
- **输入法收起**：点方向键/退格/快捷键时不再收起输入法

## 修复：局域网连接

- 连接前先探测地址是否真的可达，不再出现"显示已连接但用不了"
- 连不上时给出具体原因（不在同一 Wi-Fi / 防火墙 / 地址填错）
- 配对码自动读取，通常无需手填

## 说明

- 更新需在系统弹出的安装确认框中点「安装」（Android 14+ 的平台要求）
