# 0.2.3

## 新增：指令诊断，能直接看到每条指令的真实结果

控制面板顶部现在会显示**最近一条指令的真实情况**：

```
✓ /api/type 成功 · 23ms
✗ /api/type 失败[500]：电脑端没有准备好接收输入（注入器未就绪） · 12ms
✗ /api/type 未发出：通道不可用（局域网） · 0ms
```

输入区上方的「本地 N · 已同步 M」现在会**实时跟进**——
如果 M 不动，说明同步根本没算出来；如果 M 在涨但电脑没反应，说明指令已经发出去了。

## 修复：局域网模式下「已发指令数」永远是 0

此前这个计数只在云端模式下更新，局域网模式下一直显示 0，
让人误以为指令没发出去。现在两种模式都会如实计数。

## 说明

- 更新需在系统弹出的安装确认框中点「安装」（Android 14+ 的平台要求）
