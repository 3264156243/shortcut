# 0.2.4

## 修复：键盘点字母，电脑收到的却是快捷键

找到真正的原因了。电脑端把按键名当成 Windows 的虚拟键码使用，
而字母的小写形式对应的是**完全不同的按键**：

- 小写 `a` → 小键盘 1
- 小写 `z` → F11

所以点字母才会变成快捷键。现在字母统一按大写发送，`a` 就是 `a`。

## 新增：扫码连接局域网

控制板块的「局域网直连」上方多了「扫码连接」按钮。

直接用手机扫电脑端「局域网直连」状态卡上的二维码即可，**扫到就自动连上**，
不用再手输地址和配对码（二维码里已带好授权信息）。

手填地址的方式仍然保留，作为扫码不方便时的备用。

## 新增：连接长期保持 + 手动断开

- 连上电脑后，App 切到后台、锁屏都不会断线，连接会一直保持
- **控制页顶部有「断开」按钮**，通知栏也有「断开连接」操作
- 只有你主动断开或网络断了才会断开

## 说明

- 更新需在系统弹出的安装确认框中点「安装」（Android 14+ 的平台要求）
- 首次连接会请求「通知」权限，用于显示「正在连接电脑」的常驻提示（可拒绝，不影响使用）
