# 0.2.2

## 修复：更新下载速度过慢

下载慢不是网络问题，是**客户端自己把下载线程拖住了**。

以前每读一小块数据就刷新一次界面，35 MB 的安装包会刷新五百多次，
界面刷新占满了主线程，反过来让下载变得很慢（表现为只有几 KB/s）。

现在改成**按时间节流**刷新（约每秒 7 次），并把读取缓冲从 64 KB 提到 256 KB，
下载速度恢复正常。

## 新增：下载时显示速度与剩余时间

更新界面现在会显示**实时下载速度**和**预计剩余时间**。
这样你一眼就能看出是真慢还是只是没有反馈——以后遇到类似问题也好判断。

## 说明

- 更新需在系统弹出的安装确认框中点「安装」（Android 14+ 的平台要求）
