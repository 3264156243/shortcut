# ShortCut 灵动岛开发规划

## 1. 文档定位

本文档用于记录 ShortCut 灵动岛功能的需求边界、技术验证项、分阶段交付范围和验收标准。

- 当前状态：灵动岛基础窗口与时间显示已完成，网易云音乐模块正式界面已接入；通知与任务联动等阶段待后续开发。
- 目标平台：Windows
- 数据原则：继续复用 ShortCut 本地配置与任务数据
- 开发原则：先验证高风险系统能力，再按用户价值逐步交付
- 暂未确认的视觉和交互细节保留为空，不在实现阶段擅自决定

## 2. 产品目标

在 ShortCut 主程序内增加一个可独立开启的桌面灵动岛，以紧凑、置顶的方式聚合以下信息：

1. 网易云音乐播放信息与控制
2. Windows 系统/软件通知
3. 时间显示
4. ShortCut 待办提醒
5. 系统资源占用

灵动岛随 ShortCut 主程序启动，不增加独立的开机启动项。

## 3. 已确认的整体行为

### 3.1 窗口形态

- 默认位于主屏幕顶部正中。
- 使用独立悬浮窗口并保持置顶。
- 支持改变显示位置。
- 支持切换展示样式，具体样式方案待定。
- 无事件时显示紧凑胶囊。
- 鼠标悬停或有事件时自动展开。
- 无音乐、通知或任务事件时显示时间。
- 允许完全隐藏灵动岛。
- 提供全局快捷键控制显示与隐藏，具体键位待定。
- 可配置全屏应用运行时是否自动隐藏。

### 3.2 设置项

- 灵动岛总开关。
- 音乐模块独立开关。
- 系统通知模块独立开关。
- 时间显示模块独立开关。
- 任务提醒模块独立开关。
- 系统占用模块独立开关。
- 全屏自动隐藏开关。
- 显示位置与展示样式设置，具体控件待设计。
- 灵动岛不创建独立开机启动配置，生命周期跟随 ShortCut。

## 4. 功能需求

### 4.1 网易云音乐

目标数据：

- 专辑封面
- 歌手名
- 歌名
- 当前歌词
- 播放进度与总时长
- 播放或暂停状态

目标控制：

- 上一首
- 播放或暂停
- 下一首
- 拖动进度条跳转

展示规则：

- 收起时显示当前歌词。
- 展开时显示上一句、当前句和下一句歌词。
- 没有媒体播放时退回时间状态。

待确认或验证：

- 网易云客户端版本与兼容范围。
- 是否仅支持网易云 Windows 客户端。
- 媒体元数据、控制和进度的读取方式。
- 当前歌词和歌词时间轴的本地解析方式。
- 开源参考项目的许可证、代码结构和可复用范围。
- 是否需要 C# 原生辅助进程。

### 4.2 Windows 系统通知

目标：尽量替代 Windows 通知中心，并尽量隐藏系统原始弹窗，由灵动岛统一展示软件通知。

已确认行为：

- 普通通知到达时临时展开。
- 展示一段时间后自动收起。
- 不保存通知历史。
- 暂不支持快捷回复、通知操作按钮和复杂交互。
- 任务提醒与普通软件通知采用不同持续时间。

必须先验证：

- 当前 Windows 版本可读取的通知范围。
- 获取通知权限的用户授权流程。
- Electron 应用是否需要包身份或额外原生组件。
- 能否可靠避免灵动岛通知与系统原通知重复展示。
- 隐藏系统原始通知对全局系统设置的影响。
- 传统桌面软件、自绘通知和系统级通知的兼容边界。

约束：不得在未经用户确认的情况下永久修改 Windows 全局通知设置。

### 4.3 时间显示

时间显示属于灵动岛基础能力，随第一阶段实现。

已确认内容：

- 无事件时显示当前时间。
- 时间格式和具体视觉样式待开发时确认。
- 天气功能从当前项目范围移除，不接入天气接口和定位权限。

### 4.4 ShortCut 任务清单联动

已确认范围：

- 仅处理设置了提醒时间的任务。
- 到达提醒时间后灵动岛展开。
- 展示任务标题。
- 点击提醒后跳转到 ShortCut 对应任务墙和任务。
- 不在灵动岛中编辑任务。
- 不支持延后提醒。
- 不支持重复任务。
- 不要求全屏状态下强制显示。
- 提醒保持展示，直到用户点击或处理。

待确认：

- 点击后是否自动关闭提醒。
- 多条任务同时到期时的排序和展示方式。
- 主窗口未显示时，点击提醒如何定位并突出任务条。
- 任务已删除、任务墙已删除时的降级行为。

### 4.5 系统资源占用

当前为后续功能，开发优先级靠后。

已确认范围：

- 用户可以设置灵动岛显示哪些资源数据。
- 默认刷新间隔建议为 2 秒。
- 灵动岛隐藏或对应模块关闭时停止采集。
- 优先复用现有电脑驾驶舱的硬件采集能力，避免重复创建监控进程。

待确认：

- 可选指标清单。
- 紧凑和展开状态的布局。
- 数据异常阈值与提醒规则。
- 是否显示 CPU、GPU、内存、磁盘、网络和电池。

## 5. 状态与事件模型

灵动岛同一时刻需要选择一个主要展示状态。最终优先级待确认，初步事件类别如下：

| 事件类别 | 触发来源 | 是否自动展开 | 结束条件 |
| --- | --- | --- | --- |
| 任务提醒 | ShortCut 任务墙 | 是 | 用户点击或处理 |
| 软件通知 | Windows 通知 | 是 | 超时自动收起 |
| 音乐播放 | 网易云媒体数据 | 播放变化时短暂展开 | 返回紧凑歌词状态 |
| 时间 | 本地系统时间 | 否 | 被更高优先级状态替换 |
| 系统占用 | 现有硬件监控服务 | 待定 | 被更高优先级状态替换 |

需要在开发前确定：

- 多个事件同时到达时的展示优先级。
- 普通通知展示时长。
- 音乐切歌后的展开时长。
- 鼠标悬停是否暂停自动收起计时。
- 手动固定展开是否需要支持。

## 6. 技术架构草案

该草案仅用于指导技术验证，不代表最终实现已经确定。

### 6.1 Electron 窗口

- 由主进程管理独立的无边框透明窗口。
- 窗口默认置顶，并支持鼠标交互和点击穿透状态切换。
- 监听显示器变化，防止窗口停留在已断开的屏幕外。
- 保存位置、样式和模块开关到本地配置。
- 主窗口退出时同步销毁，不创建第二个常驻主程序。

### 6.2 原生能力

可能需要扩展现有 C# 辅助程序，统一承载以下 Windows 能力：

- 系统媒体会话读取与控制
- 系统通知读取与权限检测
- 全屏应用检测
- 已有硬件监控数据输出

是否采用一个统一辅助进程，需要在网易云与通知技术验证后决定。必须避免每个模块各自创建长期进程，防止增加内存占用。

### 6.3 前端状态

- 主进程负责原生事件和窗口生命周期。
- 渲染进程负责动画、布局与用户交互。
- 任务数据继续以现有本地 JSON 为唯一数据源。
- 高频媒体进度和硬件数据不写入 JSON。
- 窗口位置、模块开关和展示偏好写入 JSON。

## 8. 技术风险

### 高风险

- 完整替代 Windows 通知中心并隐藏原通知的可行性和权限边界。
- 网易云当前歌词的稳定解析方式。
- 透明置顶窗口在全屏、缩放、多显示器环境下的兼容性。

### 中风险

- 媒体进度拖动控制的客户端兼容性。
- 灵动岛窗口与 ShortCut 全局快捷键、截图功能的冲突。
- 长时间运行后的内存与原生辅助进程占用。

### 低风险

- 时间显示。
- ShortCut 本地任务提醒事件接入。
- 复用现有硬件监控数据。

## 9. 验收基线

每个阶段至少满足以下通用标准：

- 灵动岛关闭时不创建额外长期采集进程。
- 主窗口关闭或隐藏不会导致灵动岛状态异常。
- 不抢占普通输入框的键盘输入。
- 位置在分辨率、缩放或显示器变化后仍可恢复。
- 模块故障不得导致 ShortCut 主程序无法启动。
- 高频数据不持续写入配置文件。
- 新增原生进程必须记录内存占用并支持自动退出。
- 每次实现后同步构建 `release/win-unpacked`，提交并推送源码。

## 9.1 第二阶段验证记录

验证工具：`tools/media-validate.ps1`

用法：

- `npm run media:validate`：输出当前 Windows 媒体会话。
- `npm run media:validate -- -Lyrics`：同时请求网易云歌词。
- `npm run media:validate -- -Watch`：每秒输出一次。
- `npm run media:validate -- -Control toggle`：暂停或继续当前媒体。
- `npm run media:validate -- -Control next`：下一首。
- `npm run media:validate -- -Control prev`：上一首。

2026-08-05 在用户实际环境完成验证：

- 客户端：BetterNCM 网易云音乐 2.10.13（Build 202675，Patch 12f60b8），已开启 SMTC。
- SMTC 可读取 `cloudmusic.exe` 会话的歌名、歌手、专辑、播放状态、进度和总时长；时间线换算必须使用 `TimeSpan.Ticks`，`Duration` 在 PowerShell 投影中是方法，直接取会读到 0。
- SMTC 提供专辑图对象，但 PowerShell 无法直接投影读取流；正式实现使用网易云封面接口，SMTC 专辑图仅作为后续增强项。
- 该版本网易云的 SMTC 控制不可靠：`TryTogglePlayPauseAsync`、`TrySkipNextAsync`、`TrySkipPreviousAsync` 均返回成功但播放不变。
- 主窗口 `WM_APPCOMMAND` 的 `PostMessage` 与 `SendMessage`（原始命令码和移位后的 lParam）均未生效。
- 实际可用控制：先将网易云窗口置于前台，再用 `keybd_event` 发送媒体键。下一首 `0xB0`、上一首 `0xB1`、播放暂停 `0xB3` 均验证有效，切歌后窗口标题和 SMTC 状态同步变化。
- 本地文件均存在：`%LOCALAPPDATA%\NetEase\CloudMusic\webdata\file\history`（2.x 历史，含当前歌曲 id、时长、封面 URL）、`Library\webdb.dat`（3.x 数据库，备用）、`dumps\appParam`（版本识别）。
- 网易云搜索接口 `/api/search/get/web` 返回歌曲 id 和 `album.picId`，歌词接口 `/api/song/lyric` 返回带时间轴的完整 LRC；封面 URL 按网易云固定魔数算法生成，已确认可访问。

最终桥接方案：

- 元数据与进度：优先 SMTC；SMTC 缺失时用本地 history/webdb 或窗口标题兜底。
- 封面、歌曲 id、歌词：网易云搜索与歌词接口，必要时直接读本地 history。
- 播放控制：对网易云窗口置前台后发送媒体键，不依赖 SMTC 控制。
- 正式接入时使用一个可停止的轻量辅助进程，不在 Electron 主进程内长轮询，也不为每个模块创建独立进程。

## 9.2 第三阶段实现记录

音乐灵动岛正式界面已接入，包含：

- 紧凑胶囊：有音乐时显示当前歌词或歌曲名，无音乐时显示时间与日期。
- 展开面板：封面、歌名、歌手、专辑、上/当前/下一句歌词、播放暂停、上一首、下一首、进度条与时间。
- 进度条支持点击和拖动，调用 SMTC 跳转；BetterNCM 网易云 2.x 的 SMTC 跳转不可用，后续可通过 UI Automation 或本地辅助进程补充。
- 音乐数据由 `netmusic-bridge.ps1` 每秒轮询，只在灵动岛启用且音乐模块开启时运行，关闭灵动岛或退出程序时自动停止。
- 设置页新增音乐模块独立开关；Alt+I 仍用于显示或隐藏整个灵动岛。

## 10. 最终开发顺序

以下顺序为当前确认的正式开发路线：

1. 灵动岛基础窗口架构与时间显示。
2. 网易云媒体技术验证，实践确认最优选型。
3. 音乐灵动岛正式界面。
4. 待办任务到时提醒，以及任务条拖动到灵动岛作为任务清单。
5. Windows 通知读取技术验证，实践确认最优选型。
6. 系统程序通知拦截与灵动岛展示。
7. 接入现有电脑驾驶舱数据并显示。
8. 每日一言。

每个阶段先本地验证、提交推送；未经用户确认，不构建正式安装包或上传服务器版本。

## 12. 2026-08-02 最终技术方向

### 12.1 架构原则

- 保留现有 Electron、React、TypeScript、Vite、Zustand 主体，不迁移到 Rust、Tauri、Dioxus 或 Skia。
- 灵动岛作为新增独立 BrowserWindow 和设置页面接入。
- 主窗口、灵动岛和原有板块通过 preload IPC 通信。
- 原有快捷方式、任务墙、翻译、驾驶舱和更新功能保持独立，避免大范围重构。
- 只有在 Windows 媒体、通知或全屏检测无法用现有能力完成时，才增加一个统一、可停止的轻量原生辅助模块。
- 不为每个功能分别创建长期进程，实时数据只放内存，不持续写入 JSON。

### 12.2 参考项目结论

CAPS 位于 docs/references/CAPS（笔记：[notes/CAPS.md](references/notes/CAPS.md)），使用 MIT 许可证。可参考顶部胶囊、悬停展开、拖动定位、歌词切换动画和状态拆分；其音乐部分主要是本地播放器，不等同于读取正在运行的网易云。

NetSpeed-Dynamic 位于 docs/references/NetSpeed-Dynamic（笔记：[notes/NetSpeed-Dynamic.md](references/notes/NetSpeed-Dynamic.md)），使用 MIT 许可证。它与 ShortCut 目标最接近，可参考 Windows SMTC 媒体会话、播放控制、进度、封面、歌词多级匹配、通知和全屏避让设计；不移植其 Tauri/Rust 运行时。

WinIsland 位于 docs/references/WinIsland（笔记：[notes/WinIsland.md](references/notes/WinIsland.md)），使用 GPLv3 许可证。可参考 Windows 原生媒体 API、UserNotificationListener、通知轮询、窗口拖动和多状态渲染思路，但不直接复制 GPL 源码，避免改变 ShortCut 当前许可证边界。其文档明确提示网易云 SMTC 可能异常，因此第二阶段必须实践验证。

MIT 项目实际复制代码时保留版权和许可证声明；GPL 项目只参考行为、API 思路和架构，不复制源码。

### 12.3 资源控制

- 灵动岛关闭时停止媒体、通知和驾驶舱采集。
- 媒体和通知优先事件驱动，低频轮询只作为兜底。
- 每阶段记录 ShortCut 内存、辅助进程内存和安装包体积变化。
- 新增能力失败时显示降级状态，不得阻塞 ShortCut 启动。

### 12.4 明确移除

天气、定位权限、天气接口和天气设置不再属于当前灵动岛开发范围。
