# 参考项目索引（Reference Projects）

> **这里放什么**：外部开源项目的**本地克隆**与**阅读笔记**，用来借鉴实现思路。
> **不参与构建**：`src-tauri`、`package.json`、`vite.config.ts` 均不依赖本目录（已核实）。
>
> **两种东西分开管**：
> - **克隆的源码**（`CAPS/`、`NetSpeed-Dynamic/`、`WinIsland/` …）：只放在本地，**已加入 `.gitignore`**，
>   不进版本库（它们各自是独立 git 仓库，自己 `git pull` 更新即可）。
> - **阅读笔记**（`notes/<名字>.md`）：**进版本库**，这是给未来的自己/协作者看的资产。
>
> 历史包袱说明：这三个目录原先在 git 里是**没有 `.gitmodules` 的残缺子模块**（索引里只存了一个 commit
> 指针，clone 时拉不到内容，还会让 `git status` 永远显示一条脏标记）。2026-10-16 已从索引移除。

---

## 一、怎么用这个索引

新增一个参考项目时，做三件事：

1. 浅克隆到本目录：`git clone --depth 1 <url> <名字>`
2. 在 `notes/<名字>.md` 写一份笔记，**必须含**：定位一句话、仓库地址、**许可证**、关键源码索引、能借鉴什么、**不能借鉴什么**
3. 在下表登记一行（状态 / 功能 两个维度都填）

> ⚠️ **许可证是硬门槛**：GPL/AGPL 强传染 → **只能读思路，禁止复制或翻译任何代码**。
> MIT/Apache/BSD → 可复用，需保留版权声明。登记时必须写清。

## 二、按【状态】分类

| 状态 | 含义 | 该怎么对待 |
|---|---|---|
| 🟢 **移植参考中** | 当前正在照着它做功能 | 改动相关代码前先翻它的对应实现 |
| 🔵 **已读、结论已定** | 读完并写下了"借鉴/不借鉴"的结论 | 需要时回查笔记即可，不必再看源码 |
| 🟡 **待评估** | 听说有用、还没读 | 排期阅读，读完转 🔵 或 ⚪ |
| ⚪ **归档** | 已无参考价值（技术栈过时/思路已吸收） | 可随时删除本地克隆，笔记保留 |

## 三、按【功能】分类（维度可扩展）

| 功能域 | 说明 |
|---|---|
| `UI/灵动岛` | 胶囊/岛形态、展开收起、动画、圆角与阴影 |
| `窗口/层级` | 置顶、透明、点击穿透、多窗口与层级、DPI |
| `媒体/音乐` | 系统媒体会话（SMTC）、歌词、频谱、封面 |
| `网络/协议` | 局域网发现、中继、推送、分片传输 |
| `系统集成` | 托盘、开机自启、右键菜单、快捷键、更新 |
| `工程/架构` | 目录组织、构建脚本、内存与性能手法 |
