## 1. 项目目标

构建一个 Windows 桌面端快捷方式面板应用，核心目标如下：

1. 快速访问：通过自定义全局快捷键一键唤出/收起面板。
2. 集中管理：将常用应用、文件夹、文件、网页快捷方式集中到统一面板。
3. 结构清晰：通过分组、页签、搜索实现高频入口分层管理。
4. 体验出众：前端视觉和动效必须为重点打磨项，而不是附属项。
5. 稳定可靠：支持托盘常驻、开机启动、配置持久化与导入导出。

## 2. 目标用户与使用场景

### 2.1 目标用户
- Windows 高频操作用户
- 开发者、设计师、内容创作者、效率工具重度用户
- 希望用“面板 + 快捷键”替代桌面堆满图标的工作流用户

### 2.2 典型场景
- 快速启动常用软件（IDE、浏览器、终端、设计工具）
- 快速打开常用文件夹（项目目录、素材库、下载目录）
- 快速访问常用文档与网页
- 通过搜索在大量快捷方式中即时定位目标
- 通过分组管理不同工作模式（开发、设计、学习、娱乐）

## 3. 项目成功标准

### 3.1 功能成功标准
- 能稳定添加、打开、编辑、删除以下类型快捷方式：
  - .exe 应用
  - 文件夹
  - 普通文件
  - URL 网页
- 分组、页签、搜索、排序、导入导出功能可正常使用。
- 全局快捷键稳定呼出/关闭面板。

### 3.2 体验成功标准
- 面板整体视觉明显优于“普通工具界面”，具有现代桌面应用质感。
- 动效自然、不卡顿，交互反馈清晰。
- 高频操作路径短：新增 / 搜索 / 启动均可在 1~3 步内完成。

## 4. 范围说明（In Scope / Out of Scope）

### 4.1 本期范围（In Scope）
- 全局快捷键呼出与关闭面板（默认 Alt + Space，可自定义）
- 快捷方式管理（应用、文件夹、文件、URL）
- 分组管理与页签管理

- 复杂工作流自动化编排（非本阶段目标）

## 5. 用户故事（User Stories）

### U-01 启动面板
作为一个用户，我希望按下自定义快捷键后立即打开面板，以便快速进入操作入口。

### U-02 添加快捷方式
作为一个用户，我希望通过拖拽或手动选择，把 .exe / 文件夹 / 文件 / URL 添加到面板中。

### U-03 分组管理
作为一个用户，我希望创建多个分组，并将快捷方式归类，以保持面板整洁。

### U-04 搜索定位
作为一个用户，我希望输入关键字后快速过滤当前页签内容，以减少视觉检索成本。

### U-05 快速启动
作为一个用户，我希望点击快捷方式后立即启动对应目标，并给出清晰反馈。

### U-06 自定义快捷键
作为一个用户，我希望修改全局快捷键，以避免与其他软件冲突。

### U-07 数据备份恢复
作为一个用户，我希望导入/导出配置，以在重装系统或多机之间迁移面板布局。

## 6. 功能需求（Functional Requirements）

### 6.1 面板核心
- FR-01 支持全局快捷键唤起/关闭面板。
- FR-02 面板可拖动、可调整尺寸，并记住上次位置与大小。
- FR-03 面板在失焦时可配置为自动收起。
- FR-04 面板可固定（不因失焦关闭）。

### 6.2 快捷方式管理
- FR-05 支持新增以下类型快捷方式：应用（.exe）、文件夹、文件、URL。
- FR-06 支持拖拽文件/文件夹到面板新增。
- FR-07 支持编辑快捷方式名称、图标、目标路径、说明。
- FR-08 支持删除与确认删除。
- FR-09 支持右键菜单操作（打开、编辑、删除、复制路径、移动分组）。
- FR-10 启动失败时给出错误提示，而不是静默失败。

### 6.3 分组与页签
- FR-11 支持创建、重命名、删除分组。
- FR-12 支持在分组内对快捷方式排序。
- FR-13 支持将快捷方式在不同分组间拖拽移动。
- FR-14 支持“页签”作为顶层分类视图。
- FR-15 页签支持排序与重命名。

### 6.4 搜索与过滤
- FR-16 支持顶部搜索栏对当前页签内容进行过滤。
- FR-17 搜索应匹配名称、路径、备注等字段。
- FR-18 搜索结果需高亮匹配关键字。

### 6.5 系统与设置
- FR-19 支持修改全局快捷键（组合键录制）。
- FR-20 支持托盘常驻，并提供托盘菜单。
- FR-21 支持开机自启动开关。
- FR-22 支持主题切换（暗色/浅色）。
- FR-23 支持导入/导出配置文件。
- FR-24 支持检查目标路径是否失效，并标记“丢失目标”。

## 7. 非功能需求（Non-Functional Requirements）

### 7.1 性能
- 面板呼出响应 < 200ms（本地静态面板目标）。
- 列表滚动与动效保持 60fps 优先。
- 首次加载与大量快捷方式（>= 300）时不应明显卡顿。

### 7.2 稳定性
- 配置写入应具备容错与回退能力。
- 异常路径（目标不存在、权限不足）需统一错误处理。
- 应用崩溃后不应破坏用户配置文件。

### 7.3 可维护性
- 代码分层清晰：主进程 / 预加载 / 渲染层分离。
- UI 组件需可复用，主题与业务逻辑解耦。
- 配置结构应可扩展，避免后续新增字段导致破坏性变更。

### 7.4 可用性
- 所有核心操作应有文字、图标、状态反馈三重可感知提示。
- 空状态与错误状态必须设计，不允许空白死区。
- 高频操作优先快捷键，低频操作优先鼠标。

### 7.5 安全
- 不收集用户隐私数据。
- 仅执行用户显式添加的本地启动动作。
- 导入配置时需要进行基本格式校验。

## 8. 交互设计要求

### 8.1 打开/关闭
- 默认快捷键：Alt + Space
- 支持自定义组合键
- 面板打开时应有明确的进入动效（建议：缩放 + 淡入 + 轻微弹性）
- 面板关闭时应有对称退出动效，避免生硬消失

### 8.2 添加方式
- 方式 A：点击“添加”按钮，弹出添加表单
- 方式 B：直接将文件/文件夹拖入面板
- 方式 C：粘贴 URL 后自动识别为网页快捷方式

### 8.3 搜索交互
- 打开面板后自动聚焦搜索栏
- 输入即时过滤
- Enter 打开第一个匹配结果
- Esc 清空搜索或关闭面板（可配置）

### 8.4 分组交互
- 新建分组默认进入编辑态
- 组标题支持重命名
- 拖拽到组标题区域即入组
- 组支持折叠/展开

### 8.5 启动反馈
- 点击快捷方式后，卡片需提供点击波纹/缩放反馈
- 启动成功显示轻提示
- 启动失败显示错误提示并给出目标路径信息

## 12. 技术选型建议

### 12.1 推荐方案
- Runtime：Electron
- 前端：React + TypeScript + Vite
- 样式：Tailwind CSS + CSS Variables + 自定义设计层
- 状态管理：Zustand（轻量、适合桌面工具）
- 动效：Framer Motion
- 图标与系统能力：文件/应用图标提取、托盘、开机启动、全局快捷键
- 打包分发：electron-builder

### 12.2 选型理由
- Electron 更适合实现：全局快捷键、系统托盘、开机启动、文件拖放与本地启动
- React + Tailwind 可快速实现高质量 UI 与主题系统。
- Framer Motion 能保证动效品质和性能平衡。

## 13. 前端视觉设计标准（重点）

> 这是本项目最重要的非功能要求之一。界面不是“工具壳”，而是产品核心体验。

### 13.1 设计目标
- 整体视觉目标：现代、干净、克制、沉浸
- 必须具备“精品桌面效率工具”的质感，而不是普通网页后台感
- 风格关键词：玻璃拟态（Glassmorphism）、微光影层次、柔和阴影、精致圆角、细腻排版、稳定网格秩序

### 13.2 主题规范
#### 暗色主题（默认）
- 背景：深灰偏冷底，而非纯黑
- 卡片：半透明磨砂，带轻微内发光
- 文字：高可读灰白层次，不做纯白刺眼处理
- 强调色：一套主色 + 一组辅助色
- 阴影：柔和、扩散、偏冷色阴影

#### 浅色主题
- 背景：干净浅灰或白底
- 卡片：柔和阴影，轻边界
- 文字：深灰层级分布
- 避免廉价塑料感

### 13.3 布局标准
- 统一 8px 栅格节奏（8 / 12 / 16 / 20 / 24 / 32）
- 卡片统一圆角半径，例如 16px 或 12px（二选一全项目统一）
- 网格对齐严格一致，不允许图标错行、文字跳格
- 页签、搜索栏、组标题高度统一

### 13.4 卡片设计
- 默认态：半透明底、细描边、柔和投影
- 悬停态：轻微上浮（2~4px）、阴影扩大、背景亮度轻微提升
- 点击态：轻压缩回弹（scale 0.98）、波纹或高亮扩散反馈
- 失效态（路径不存在）：明确标记“目标丢失”、图标降低饱和度

### 13.5 图标规范
- 快捷方式图标尺寸统一（例如 40 / 48 / 56 三档，项目统一一档主尺寸）
- 图标需支持：应用原生图标、文件夹图标、URL 网站 favicon / fallback、自定义图标上传
- 图标周围保留安全留白，不允许贴边

### 13.6 排版规范
- 标题、副标题、正文、辅助文字至少 3 级层次
- 行高建议：标题 1.2；正文 1.4~1.6
- 文字截断统一规则：单行截断、多行备注截断（如 2 行）
- 字体建议：中文系统默认黑体类字体即可；英文/数字优先等宽或现代无衬线字体

### 13.7 动效规范
- 动效原则：快速、轻盈、有方向感
- 建议时长区间：微交互 120~180ms；面板展开/收起 200~280ms；页面切换 200~320ms
- 曲线建议：常规 ease-out；弹性轻微 spring（不宜过弹）
- 禁止：大面积旋转特效、拖沓慢动效、闪烁/抖动/霓虹风格

### 13.8 搜索栏设计
- 搜索栏必须是视觉重心之一
- 聚焦时需有柔和高亮边框/外发光
- 搜索图标、占位符、清空按钮必须精致统一
- 结果过滤时需有平滑列表过渡，而不是硬切换

### 13.9 状态设计
- 空状态：提示文案 + 插图/图标 + 主操作按钮
- 加载状态：骨架屏或轻量 shimmer（如需要）
- 错误状态：明确错误说明 + 重试/修复入口
- 成功状态：轻量 toast，不打断主流程

### 13.10 设计验收标准（用于开发后比对）
- 任意放大到 125% / 150% 时，布局不破、文字不挤
- 暗色主题下不存在刺眼纯白块
- 卡片悬停与点击反馈统一，不允许部分有动效、部分无反馈
- 图标大小、间距、圆角全应用一致
- 搜索、分组、页签三者视觉风格一致，不出现风格分裂
