# 岛窗口文件拖拽识别与转换交互改造（需求 + 实施计划）

> 术语：**岛窗口 = `island` 窗口（SC 球）**；`deepseekball` 是「旁边的小球」，本需求不涉及它（只跟随岛的穿透状态）。
> 分支 `codex/tauri2-migration`；本轮不产出安装包，只出本地可运行 exe 供验收。

---

## 一、总体目标

把「拖动文件/文件夹到岛窗口」的交互**全部收敛到岛窗口内部**（不再用窗口外的描边/额外区域），
并补完 **识别 → 展示 → 按钮选择 → 转换进度 → 完成反馈 → 自动打开目录 → 复位** 全流程；
按钮组件做成**可复用**（后续文件类型增多时按钮数量可不同），默认格式与自动打开目录**可配置**。

---

## 二、逐条需求与设计决策

| # | 需求 | 设计决策 |
|---|---|---|
| 1 | 移除「停止穿透」状态顶部标签 | 直接删除 `IslandDrop.tsx` 里右上角「穿透中 · Ctrl+Alt+B」标签及样式（`.island-drop-passthru`）。穿透状态仍写日志 + Windows ex-style 回读，便于排障 |
| 2.1 | 拖拽悬停态：移除蓝色虚线描边；识别区域仅限岛窗口自身；窗口内显示「松手自动识别」；可高亮/放大 | 删除 `.island-drop-outline`；岛自身加 `drop-hover` 类（轻微放大 + 高亮描边贴岛胶囊）；岛窗口内（胶囊位置）显示「松手自动识别」。落点判定仍 = 岛窗口矩形（不再有任何向下延伸区域） |
| 2.2 | 识别完成后窗口内文字 = 文件名 + 格式；过长省略中间、保留首尾 | 岛窗口内同位置显示 `名字(中间省略).ext` + 类型徽标；中间省略用 JS 计算字符预算（`midEllipsis`），CSS `text-overflow` 兜底 |
| 2.3 | 识别完成后岛下方自动弹出椭圆按钮，按类型区分 | 岛窗口内胶囊下方渲染**胶囊形按钮行**（组件 `PillActions`，可复用、数量可变）：压缩包 = 解压 / 取消；图片 = 压缩(zip) / 转为(png\|jpg + 下拉) / 取消；音频 = 压缩(zip) / 转为(WAV + 下拉) / 取消。压缩/图片/音频的默认格式取设置 |
| 2.4 | 转换时窗口内容变进度条；完成后上方显示「转换完成」停留 1 秒；自动打开所在目录并选中；按钮自动关闭；窗口恢复转换前内容 | 岛内同一位置渲染进度条（真实百分比来自 `converter:progress`，缺失时不确定态动画）；完成 → 「转换完成」保持 1s → `revealInExplorer(输出)`（`explorer /select,`）→ 收起按钮 → 复位到 idle（岛原本的余额/歌词/时间内容不被破坏，因为遮罩层只覆盖胶囊区） |
| 三.1 | 压缩/图片/音频默认格式可在「转换面板 → 设置面板」选择 | 新增 `converter.defaults = { compress, image, audio }` 配置 + 转换面板设置区下拉；岛按钮与右键菜单/转换面板共用读取 |
| 三.2 | 「转换完成后自动打开目录」可开关 | 新增 `converter.autoReveal: true/false` + 设置开关；关闭时不打开目录、只在岛上显示完成 |
| 三.3 | 椭圆按钮组件可复用 | `src/components/PillActions.tsx`：`items: {key,label,tone,disabled,select?}[]`，数量可变、自动换行；下拉用同一组件的 `select` 变体 |

### 不做 / 边界
- 7z / rar **不支持**解压（无解码器），它们只给「压缩」按钮。
- 不做安装包、不做打包发布（等用户发话）。
- 不改变岛窗口尺寸（保持 360×340，Electron 规格一致），所有交互都在岛窗口内部渲染。

## 三、拆分计划（按序执行，每轮自测 + 提交）

### P0 基线与文档（本轮）
- 落本 MD；确认现状代码位置（`src/IslandDrop.tsx`、`src/islandDrop.css`、`windows.rs::set_ball_shape`、`converter` 事件）。

### P1 移除标签 + 悬停态收敛到岛内
- 删 `.island-drop-passthru` 标签与样式；删 `.island-drop-outline` 蓝色虚线。
- 岛内胶囊位置新增 `IslandDrop` 遮罩层：空闲时**完全不渲染**（不挡岛本来的内容）。
- 悬停：`drag-over` → 遮罩显示「松手自动识别」+ 岛 `drop-hover` 放大高亮。
- 验收：拖文件进岛 → 岛内出现「松手自动识别」，岛轻微放大，无蓝色虚线、无额外区域；离开 → 复原。

### P2 识别结果展示（文件名 + 格式，中间省略）
- `converterDetect` 结果落到遮罩：`<类型徽标> 名字…ext`；多文件显示「等 N 个文件」。
- `midEllipsis(name, 24)`：保留首尾，中间 `…`；同时 CSS 兜底。
- 验收：长文件名（例如 60 字符）显示为「前缀…后缀.png」。

### P3 可复用胶囊按钮组件 + 各类型按钮集
- 新增 `PillActions.tsx`（含 `select` 变体）并在岛上渲染。
- 压缩包：解压 / 取消；图片：压缩 / 转为(默认图片格式) + 下拉 / 取消；音频：压缩 / 转为(默认音频格式) + 下拉 / 取消；其它：取消（+ 打开转换面板）。
- 验收：三类文件分别出现对应按钮；「取消」关闭按钮并复位；下拉可选其他格式。

### P4 转换执行 + 进度 + 完成反馈 + 自动打开目录
- 进度：`converterConvert/Extract` 返回 id → 订阅 `converter:progress`（无则不确定态）→ 岛内进度条。
- 完成：岛内「转换完成」保持 1s → `revealInExplorer(输出 / 解压目录)` → 收起按钮 → 复位。
- Rust 新增 `revealInExplorer`（`explorer /select,"<path>"`，目录则直接打开）。
- 验收：选 ZIP → 进度 → 「转换完成」→ 资源管理器打开并选中产物；岛上恢复原内容。

### P5 设置（默认格式 + 自动打开目录开关）
- 转换面板「设置」区：压缩默认格式、图片默认格式、音频默认格式、自动打开目录开关。
- 落盘 `config.converter.defaults.*` / `config.converter.autoReveal`；岛按钮默认值跟随。
- 验收：改默认格式 → 岛上按钮文字随动；关自动打开 → 转换完成后不弹资源管理器。

### P6 回归与文档收尾
- 回归：穿透开/关都能拖入（守卫）；小球跟随穿透；快捷键 `Ctrl+Alt+B` 不变；`cargo test` 20 项全过；前端 `npm run build`。
- 更新 `docs/tauri-regression.md`（新增本轮结论）与本文档「实施记录」。
- 提交 + 推送 + 中文验收步骤。

## 四、验收清单（交付时逐条过）

1. 岛上不再有任何「穿透」标签；蓝色虚线描边消失。
2. 拖入悬停：岛内出现「松手自动识别」，岛有高亮/放大反馈，落点只在岛窗口内。
3. 识别完成：岛内显示「文件名 + 格式」，长名中间省略、首尾可辨。
4. 岛下方弹出椭圆按钮：压缩包(解压/取消)、图片(压缩/转为+下拉/取消)、音频(压缩/转为+下拉/取消)。
5. 转换中：岛内变进度条；完成后岛上方「转换完成」停留约 1 秒。
6. 完成后：自动打开所在目录并选中产物；按钮自动关闭；岛恢复转换前内容。
7. 设置里可选压缩/图片/音频默认格式；可开关「转换完成后自动打开目录」。
8. 穿透开/关两种状态下都能拖入；`Ctrl+Alt+B` 与设置开关行为不变。
