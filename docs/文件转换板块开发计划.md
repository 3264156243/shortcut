# 文件转换板块开发需求计划

> 版本：v1.0 定稿（需求确认：2026-09-30）
> 目标版本：2.4.6（与 Tauri2 迁移修复一同打包发布）
> 分支：codex/tauri2-migration

---

## 1. 背景与目标

在主面板新增"**转换**"板块（与快捷/任务/驾驶舱/翻译并列），提供本地离线的文件格式转换能力：

- **音频**常见路径互转
- **图片**常规格式互转
- **解压缩**（zip + tar 系全支持，读与生成）
- md/txt/html 互转**本期不实现，架构预留**（后续按需扩展更多格式）
- Windows 资源管理器**右键菜单集成**（本软件注册的转换/解压缩入口）

核心原则：**纯本地离线、隐私安全、安装包体积可控**（不内嵌 ffmpeg 全家桶）。

---

## 2. 功能范围（一期定案）

### 2.1 音频转换

**输入格式（解码，symphonia 全覆盖）**：

| 格式 | 容器/编码 | 支持 |
|---|---|---|
| .wav | PCM/ADPCM | ✅ |
| .mp3 | MPEG L3 | ✅ |
| .flac | FLAC | ✅ |
| .ogg | Ogg Vorbis | ✅ |
| .m4a / .aac | MP4/AAC | ✅ |
| .opus | Ogg Opus | ✅ |
| .wma | ASF/WMA | ❌ 纯 Rust 无解码器 → 二期可选 ffmpeg 外挂通道 |

**输出格式（编码）**：

| 格式 | 编码器 | 说明 |
|---|---|---|
| .wav | 手写 PCM 容器 | 无损，零依赖 |
| .mp3 | mp3lame-encoder（纯 Rust 绑定 LAME） | 支持码率选择（默认 192k，可选 128/192/256/320） |
| .flac | flacenc（纯 Rust） | 无损 |
| .opus | opus crate（静态链接 libopus） | 有损高质量，体积小 |

**转换矩阵**：7 输入 × 4 输出 = 28 条路径。
**明确不支持（一期）**：ogg-vorbis 编码、aac/m4a 编码、wma 解码（见 §9 扩展通道）。

### 2.2 图片转换

**输入（解码）**：png / jpg / webp / bmp / gif / tiff / ico
**输出（编码）**：png / jpg（质量可选）/ webp（无损）/ bmp / tiff / ico（多尺寸生成）

- 基于 `image` crate（纯 Rust，成熟稳定）
- gif 输出取首帧静态化（动图编辑不在范围）
- ico 输出自动生成多尺寸（16/32/48/64/128/256）

**明确不支持（一期）**：avif（编码慢）、heic（纯 Rust 不可行 → 二期 ffmpeg 外挂）、svg 输入（resvg 预留接口，按需加）。

### 2.3 解压缩

| 能力 | 格式 | 实现 |
|---|---|---|
| 解压 | .zip（含 ZipCrypto/AES 密码） | zip crate |
| 解压 | .tar / .tar.gz / .tar.bz2 / .tar.xz / .tar.zst | tar + flate2/bzip2/xz2/zstd |
| 解压 | .gz / .xz / .bz2 / .zst 单文件 | 同上 |
| 压缩 | .zip（可选密码、压缩级别） | zip crate |
| 压缩 | .tar / .tar.gz / .tar.bz2 / .tar.xz / .tar.zst（文件或文件夹） | 同上 |
| ❌ | .7z 解压（sevenz-rust 备选）、.rar 解压（需 C 库 unrar） | 二期评估 |

**冲突处理**：同名文件三选一（覆盖 / 自动重命名 / 跳过），默认自动重命名（file.txt → file(1).txt）。

### 2.4 文档转换（本期不实现，架构预留）

md/txt/html 互转方向暂缓（用户确认）。转换板块架构按"**格式注册表**"设计（§6.3），后续扩展只需注册新的转换器实现，不动框架：

- 预留一期后可加：md→html（pulldown-cmark）、html→md、纯文本互转
- 更远期：md→pdf/docx（排版引擎）、视频转音频

## 3. 交互设计

### 3.1 板块布局（主面板"转换"板块）

```
┌──────────────────────────────────────┐
│  [拖放区]  拖入文件或点击选择          │
│  （自动识别类型，显示格式图标）         │
├──────────────────────────────────────┤
│  文件列表：                           │
│  🎵 song.mp3 (5.2MB)  → [wav ▾] [转换]│
│  🖼 photo.png (2.1MB) → [jpg ▾] [转换]│
│  📦 data.zip          → [解压到…]     │
│  （批量：全部转换为…）                 │
├──────────────────────────────────────┤
│  输出目录：同目录 ▾（可改为固定目录）   │
├──────────────────────────────────────┤
│  历史记录（可删单条/清空）             │
│  ✅ song.wav · 10:32 · 打开/定位       │
└──────────────────────────────────────┘
```

### 3.2 交互规则（用户已确认）

1. **拖放或选取**文件 → 自动识别类型 → 显示对应目标格式下拉 → 转换
2. **默认输出同目录**，可修改为固定目录（记住上次选择）
3. **批量转换**：多文件逐个处理，逐条显示进度/成功/失败
4. **转换历史**：持久化存储，可删除单条、可清空；条目可点击打开文件/所在目录
5. 同名冲突：自动重命名（默认），失败条目标红可重试

## 4. 实现方式评估与决策

### 4.1 三种方案对比

| 维度 | A. 纯 Rust 库（✅ 选定） | B. 内嵌 ffmpeg | C. 云 API |
|---|---|---|---|
| 格式覆盖 | 覆盖需求 90%（缺口：aac/heic/wma 编解码、ogg 编码） | 100% | 100% |
| 安装包体积 | **+6~8MB**（总 ~12MB） | +80~100MB（总 ~100MB） | 0 |
| 隐私 | **全离线** | 全离线 | 文件上传第三方 |
| 网络 | 无依赖 | 无依赖 | 必须联网 |
| 费用 | 免费 | 免费 | 按量付费 |
| 进程管理 | 无外部进程 | 需管理 ffmpeg 子进程/退出清理 | HTTP 客户端 |
| 许可 | MIT/Apache 为主，LAME GPL？→ 用 LGPL 替代或纯实现需核实 | LGPL 构建配置繁琐，GPL 组件易误带 | 服务商条款 |
| 失败面 | 库成熟度高，边界格式可能失败 | 兼容性最好 | 服务商故障/限速 |

### 4.2 决策

**采用方案 A（纯 Rust 库）**，理由：

1. 用户需求矩阵（音频常见路径 + 常规图片 + zip/tar 系）纯 Rust **全覆盖**，缺口项均非主路径
2. 软件是本地工具（便签/任务全本地），隐私一致性重要
3. 安装包 4MB → ~12MB，仍远小于 Electron 版 98MB
4. 无外部进程管理（对比 Electron 音乐桥/硬件监控的孤儿进程教训）

**缺口兜底**：架构预留 `ExternalToolConverter` 通道（§6.3），未来若强需 aac 编码/heic/wma，可在设置里让用户指定系统 ffmpeg 路径启用增强模式——**不打包、不强依赖**。

## 5. 资源管理器右键菜单集成

### 5.1 方案：注册表（经典 shell 菜单）

**写入位置**（NSIS 安装器自动执行，HKCU 无需管理员）：

```
; 所有文件的"ShortCut 转换"入口
HKCU\Software\Classes\*\shell\ShortCutConvert
    MUIVerb = "用 ShortCut 转换"
    Icon    = "<安装目录>\shortcut-tauri.exe"
    SubCommands = ""            ; 直接触发，打开转换板块并载入该文件

HKCU\Software\Classes\*\shell\ShortCutConvert\command
    (默认) = "<安装目录>\shortcut-tauri.exe" --convert "%1"

; 压缩包右键"解压到当前文件夹"
HKCU\Software\Classes\.zip\shell\ShortCutExtract\command
HKCU\Software\Classes\.rar\shell\...
HKCU\Software\Classes\.7z\shell\...
    (默认) = "<安装目录>\shortcut-tauri.exe" --extract "%1"
```

- 卸载时 NSIS 删除注册表键
- 设置里提供开关（写/删注册表）与说明

### 5.2 参数链路

```
右键 → 启动 shortcut-tauri.exe --convert "C:\path\file.png"
     → tauri-plugin-single-instance 二实例退出，参数转发给已运行实例
     → Rust 收到 args → emit converter:open { files: [...] } 给主窗
     → 前端切到转换板块，文件列表预填，用户选目标格式开始
```

**Win11 限制说明**：注册表方式在 Win11 新右键菜单里需点"显示更多选项"可见；IExplorerCommand COM 集成（出现在一级菜单）工作量大，列为二期。

## 6. 架构设计

### 6.1 Rust 模块（src-tauri/src/）

```
converter/
  mod.rs        # 入口：detect_kind()、convert()、extract()、compress()
  detect.rs     # 类型探测（魔数优先 magic bytes，扩展名兜底）
  audio.rs      # symphonia 解码 + mp3lame/flacenc/opus/wav 编码
  image.rs      # image crate 编解码 + ico 多尺寸
  archive.rs    # zip/tar 系读写 + 冲突重命名
  history.rs    # converter-history.json 读写（独立文件，不污染 config.json）
  events.rs     # 转换进度/完成/失败事件（converter:progress / :done / :error）
```

### 6.2 invoke 接口（electron_api 新分支）

| 方法 | 参数 | 返回 |
|---|---|---|
| converterDetect | paths[] | 每文件 {kind, ext, size, suggestTargets[]} |
| converterConvert | path, target, options{quality/bitrate/outDir} | 异步启动，事件回报 |
| converterExtract | path, outDir?, conflictMode | 同上 |
| converterCompress | paths[], format, outPath, options{password, level} | 同上 |
| converterHistory | — | 历史列表 |
| converterHistoryRemove | id / clear | — |
| converterPickDir | — | 文件夹选择对话框 |

### 6.3 格式注册表（可扩展核心）

```rust
trait Converter {
    fn kind(&self) -> Kind;                       // Audio / Image / Archive / Doc
    fn accepts(&self, ext: &str, magic: &[u8]) -> bool;
    fn targets(&self, src: &str) -> Vec<Target>;  // 该源可转的目标列表
    fn convert(&self, job: &Job) -> Result<PathBuf>;
}
// registry: Vec<Box<dyn Converter>> —— 新格式=新实现+注册，框架零改动
// Doc 预留：DocConverter 空实现占位，字段/事件/UI 复用
```

### 6.4 前端

- 主面板新增"转换"板块（板块注册表加入，Space 循环切换自动包含）
- 组件：`ConverterPanel.tsx`（拖放区/文件列表/格式下拉/批量栏/输出目录/历史）
- 状态：store 增加 converter 段（队列/进度/历史）；事件监听 converter:progress/done/error

## 7. 依赖清单与体积预估

| crate | 用途 | 体积增量 |
|---|---|---|
| image | 图片编解码 | ~1.5MB |
| symphonia | 音频解码（mp3/flac/ogg/aac/opus/wav） | ~2MB |
| mp3lame-encoder | mp3 编码 | ~0.3MB |
| opus (libopus 静态) | opus 编码 | ~0.6MB |
| flacenc | flac 编码 | ~0.3MB |
| zip | zip 读写 + AES | ~0.5MB |
| tar + flate2 + bzip2 + xz2 + zstd | tar 系压缩 | ~0.8MB |
| walkdir /同族 | 文件夹遍历 | ~0.1MB |
| **合计** | | **+6~8MB**（安装包 4MB → ~12MB） |

构建注意：opus/xz2/bzip2/zstd 为 C 绑定，build.rs 走 cc——MSVC 工具链已具备（现有构建环境即可）。

## 9. 风险与备选

| 风险 | 影响 | 备选 |
|---|---|---|
| symphonia 个别损坏/特殊编码文件解码失败 | 单文件转换失败 | 错误信息明确提示"格式不受支持或文件损坏"；ExternalToolConverter 通道兜底 |
| mp3lame 许可（LAME 历史为 LGPL+专利过期） | 分发合规 | 专利 2017 年已全部过期；LGPL 动态/静态合规使用即可，发布前复核 |
| libopus C 编译在 CI/新环境失败 | 构建阻塞 | opus-sys 带 vendored 源码；失败则 opus 输出降级为可选项 |
| 大文件转换内存占用 | 体验 | 流式处理（symphonia 逐帧→编码器逐块），单文件内存 <50MB |
| Win11 右键二级菜单用户嫌深 | 触达 | 二期 IExplorerCommand COM；先验证使用率 |
| 转换历史膨胀 | 存储 | 上限 200 条自动滚动淘汰 |
